01 · the ailment

the problem this solves — why existing tools fail

Every other tool
takes your cursor.

Anthropic's computer-use MCP needs per-app manual approval and moves the real pointer. AppleScript is decades old and has no verification. Hammerspoon scripts Lua but has no agent integration and no evidence of what happened.

Worse: accessibility APIs routinely lie. AXSetValue reports success on WebKit while changing nothing. AXPerformAction succeeds on background menus that were never validated. Every tool that trusts return codes builds on sand.

02 · the tentacles

the solution — how it works, what makes it unique

Five tentacles,
tried in order.

Every action is delivered by the least invasive means that works. Accessibility writes first. Per-process posted events second. App-specific referrals third. The cursor-stealing hardware path — the sting — only when you opted in and everything else failed.

Content for this section — the features, not the implementation:

Ghost input — most actions reach apps without moving the cursor or changing focus. Type into a background TextEdit while playing a game.

Evidence verdicts — confirmed / noEffect / unverifiable. The reply tells you what happened, verified by read-back, pixel comparison, window count, or process exit. noEffect catches the lies.

The visible agent — when the cursor IS taken, a jellyfish escorts it, a bezel narrates what's happening, and a charge-up sigil gives you time to stop it. Touch the mouse → it yields. ⌃⌥⇧⎋ → everything stops in ~8 ms.

Diff perception — read an app's text for 1/1000th of a screenshot. Pass the token back, get only what changed: elements appeared, vanished, values moved. Screenshots diff the same way: crops, not frames.

Virtual display — park a window onto an invisible screen, work on it with full hardware input, put it back. No screen real estate, no occlusion.

Sequence plans — execute multi-step flows as one atomic daemon-side operation with postcondition guards between steps. No round-trips, no race conditions.

— The daemon keeps the display awake during sessions (released after quiet minutes)
